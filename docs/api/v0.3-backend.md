# v0.3 Backend API

The v0.3 backend is a local lightweight proxy that keeps `OPENAI_API_KEY` out of the iOS app.

## Run

```bash
cd backend
cp .env.example .env
python3 server.py
```

If `OPENAI_API_KEY` is empty and `MOCK_MODE=auto`, endpoints return mock responses.

## Endpoints

### `GET /health`

Returns:

```json
{
  "ok": true,
  "mock": true
}
```

### `POST /speech/transcribe`

Request:

```json
{
  "file_name": "recording.m4a",
  "audio_base64": "..."
}
```

Response:

```json
{
  "text": "I was about to grab some coffee. Do you want anything?",
  "model": "gpt-4o-transcribe",
  "mock": false
}
```

### `POST /speaking/score`

Request:

```json
{
  "target": "I was about to grab some coffee. Do you want anything?",
  "transcript": "I was about to get coffee..."
}
```

Response:

```json
{
  "clarity": 82,
  "fluency": 76,
  "completeness": 88,
  "naturalness": 73,
  "summary": "整体能表达清楚...",
  "suggestions": ["..."],
  "missed_keywords": ["anything"],
  "model": "gpt-4.1-mini",
  "mock": false
}
```

## Notes

- iOS should call the backend, not OpenAI directly.
- Audio is sent as base64 JSON for the first prototype. This is simple but not ideal for large files.
- A later version can switch to multipart upload from iOS to backend.
- OpenAI audio transcription uses `/v1/audio/transcriptions`.
- Speaking feedback uses the Responses API with structured JSON output.
