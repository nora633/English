# Flutter 跨端迁移

## 目标

把原来的 SwiftUI iOS 原型迁移为 Flutter 移动端工程，用一套前端代码同时支持 iPhone 和 Android。

## 当前结构

```text
英语学习app/
  mobile/              # Flutter 跨端 App
    lib/
      main.dart        # App 入口
      src/
        app.dart       # MaterialApp 配置
        app_shell.dart # 底部导航和页面切换
        data/          # 静态样例数据
        models/        # 学习领域模型
        services/      # 本地进度存储等轻量服务
        theme/         # 颜色与文字样式
        views/         # 今日、素材、跟读、翻译、复盘页面
        widgets/       # 公共 UI 组件
  backend/             # Python 后端原型
  EnglishLearningApp/  # 旧 SwiftUI 原型，作为产品和交互参考
  docs/
```

## 已迁移范围

- 今日：15 分钟任务卡、完成状态、精听 5 句、关键单词、日常语法结构、今日词块。
- 素材：阶段筛选、素材列表、素材详情、合法内容展示说明、生成练习入口。
- 跟读：目标句、真实录音基础、本地录音回放、录音草稿、评分、转写、建议、听写、默写、进入复盘。
- 翻译：中文输入，同步生成英文、韩文敬语、韩文平语、韩语读音，并提供朗读入口。
- 复盘：连续学习、累计分钟、最近记录、错词错句、明日推荐、可迁移表达、今日词块和明日重点。
- 本地存储：跟读、听写、默写完成状态按日期保存到设备本地，重启 App 后可恢复当天进度，第二天自动从新的 0/15 开始。
- 本地统计：保存累计分钟、连续完成天数、最近 7 条学习记录和近 7 天错词错句。

## 移动端视觉适配

- Web/桌面预览时把 App 内容限制在 430px 宽度内，更接近手机实际观感。
- 底部导航改为悬浮圆角样式，避免像桌面网页导航。
- 页面底部保留安全间距，防止最后一张卡片被底部导航遮挡。

## 推荐逻辑

每日 15 分钟训练按以下优先级生成：

1. 先根据学习阶段推进：日常表达 -> 影视歌曲 -> 新闻听读 -> 报刊精读。
2. 同阶段内优先复习昨天暴露的弱项。
3. 每天内容配比：60% 复习弱项、30% 同级新场景、10% 轻挑战。
4. 只有当前阶段稳定后，再增加更难的新闻稿或报刊读物。

## 验证结果

```bash
cd mobile
flutter test
flutter build web
```

两项已通过。Android 工具链已通过 `flutter doctor`，首次 `flutter build apk --debug` 会触发 NDK 下载，当前网络下曾长时间等待，可在网络稳定后重试。
