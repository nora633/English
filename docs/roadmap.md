# 版本路线图

## v0.1.0 - 项目定义

目标：把产品方向、学习闭环和迭代方式固定下来。

- 建立 Git 仓库。
- 创建 README、产品规格和版本路线图。
- 创建 GitHub private repo 设置指南。
- 明确 MVP 范围、内容版权边界和技术方向。
- 后续开始原型设计前，所有新增想法先记录到文档或 issue。

验收标准：

- 项目可以通过 Git 追踪。
- 项目知道如何安全连接 GitHub private repo。
- 下一阶段开发者能理解产品目标和 MVP 功能。

## v0.2.0 - iOS 静态原型

目标：做出可点击但不接真实 AI 的 SwiftUI 原型。

- 状态：已启动，SwiftUI 静态原型骨架已创建，并已在 iPhone 模拟器运行成功。
- 今日学习页。
- 主题选择页。
- 听力跟读页。
- 句子听写/默写原型。
- 今日页展示完成状态、完成进度、5 句精听、关键单词和日常语法结构。
- 跟读页按跟读、听写、默写的顺序逐步展示。
- 素材详情页展示不同类型素材的 mock 视频/歌词/新闻/文章内容。
- 复盘页展示基于“主线进阶 + 弱项复习 + 兴趣调味”的明日推荐 mock 结果。
- 口语反馈页。
- 学习复盘页。
- 素材主题展示从日常表达到新闻/报刊读物的进阶路径。

验收标准：

- 可以在 iPhone 模拟器跑通完整 15 分钟学习流程的页面跳转。
- 所有页面使用 mock 数据。

## v0.3.0 - 本地离线学习闭环

目标：不依赖服务器，让 App 可以作为自用/少量朋友试用的离线版本持续记录学习状态。

- 状态：已完成 Flutter 版核心闭环。
- 支持本地保存跟读、听写、默写完成状态。
- 支持按日期隔离学习进度，第二天自动从新的 0/15 开始。
- 支持连续完成天数、累计分钟和最近历史记录。
- 支持听写/默写后沉淀错词错句。
- 支持首页关键单词进入详情页，查看读音、词根、联想记忆、搭配和易混点。
- 支持移动端视觉优化：底部导航遮挡层、素材白色卡片、按钮均分布局。

验收标准：

- 用户完成跟读、听写、默写后，首页进度实时更新。
- 用户关闭并重新打开 App 后，当天进度仍能恢复。
- 第二天打开 App 时，今日进度从 0/15 开始，历史记录保留。
- 复盘页能看到连续天数、累计分钟、最近记录和错词错句。

## v0.4.0 - 真实听说评分

目标：加入真实录音、播放、听写/默写评分和 AI 反馈。

- 状态：本地自用 MVP 已完成，准备进入 Android APK 打包测试；AI 真服务留到后续版本。
- 支持申请麦克风权限、录音状态切换、录音草稿提示和本机临时音频路径。
- 支持 iOS / Android 麦克风权限配置。
- 支持测试录音器注入，避免自动化测试依赖真实设备麦克风。
- 支持录音保存入口、本地音频回放和本地学习进度联动。
- 支持独立翻译 Tab：中文输入后展示英文、韩文敬语、韩文平语和韩语读音。
- 支持翻译结果朗读入口，优先调用设备系统 TTS。
- 支持翻译历史记录和结果复制。
- 支持学习数据备份码导出/导入，用于 Android 和 iPhone 手动迁移。
- 明确标注本地自用版边界：无账号、无自动云同步、AI 评分/转写/翻译暂为本地原型。

验收标准：

- 用户可以完成一次 15 分钟学习流程，并在复盘页看到本地记录。
- 用户可以使用翻译页查看英文、韩文敬语、韩文平语和韩语读音。
- 用户可以生成备份码并导入到另一台设备。
- 测试、Web 构建和静态检查通过。

## v0.4.x - AI 能力补强

目标：在本地自用版稳定后，逐步接入真实 AI 能力。

- 后端代理 AI 调用，客户端不保存 API key。
- 支持录音上传和语音转写。
- 支持基于转写文本生成口语反馈。
- 支持听写/默写答案校验、漏词标记和自然表达建议。
- 支持翻译页从本地规则升级为后端 AI 翻译。

## v0.5.0 - 兴趣内容系统

目标：让学习内容更贴近剧集和歌曲兴趣。

- 支持搜索剧集或歌曲主题。
- 支持保存素材元数据和公开视频链接。
- 支持手动粘贴合法短片段生成学习任务。
- 支持 AI 生成相似生活情景对话。

验收标准：

- 用户可以围绕一个喜欢的作品主题生成当天学习任务。
- App 不保存完整剧本、完整歌词或盗版字幕。

## v0.6.0 - 个人 Beta

目标：让 App 具备连续使用价值。

- 学习日历。
- 连续学习天数。
- 口语评分趋势。
- 词块复习。
- 历史记录搜索。

验收标准：

- 连续使用 7 天后能看到清晰的进步记录。
- 能回看过去学习过的表达和反馈。

## v1.0.0 - 稳定自用版

目标：达到稳定、顺手、可长期个人使用。

- 修复核心崩溃和卡顿。
- 完善隐私说明。
- 完善数据备份策略。
- 整理配置文档。
- 固化发布流程和 tag 规范。

验收标准：

- 能稳定运行一周以上。
- 每日学习流程少于 3 次点击即可开始。
- API key、录音和个人学习数据不会被误提交到 Git。
