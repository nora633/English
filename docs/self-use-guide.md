# 自用版使用说明

## 当前版本

- 版本：v0.4.0
- App 名称：外语岛
- 技术形态：Flutter 跨端 App，一套代码支持 Android 和 iPhone。
- 当前定位：本地自用 MVP，先让自己开始每天练习。

## 已可用功能

- 今日学习：15 分钟听说训练、5 句精听、关键单词、日常语法。
- 素材：日常表达、影视歌曲、新闻听读、报刊精读等主题。
- 跟读：录音、停止、保存、回放、听写、默写。
- 复盘：连续天数、累计分钟、最近记录、错词错句、明日推荐。
- 翻译：中文转英文、韩文敬语、韩文平语、韩语读音、朗读、复制、历史记录。
- 数据备份：生成备份码、导入备份码。

## 当前限制

- 不需要服务器，也没有账号登录。
- Android 和 iPhone 之间不会自动同步。
- 如果要换手机，用复盘页的“数据备份”生成备份码，再到新手机导入。
- 口语评分、语音转写和翻译当前是本地原型结果，不是真 AI 服务。
- 正式 AI 评分、AI 翻译和云同步会放到后续版本。

## Android 安装思路

1. 在电脑上生成 APK。
2. 把 APK 传到 Android 手机。
3. 手机允许安装未知来源应用。
4. 打开 APK 安装。

后续打包命令：

```bash
cd mobile
flutter build apk --debug
```

生成文件通常在：

```text
mobile/build/app/outputs/flutter-apk/app-debug.apk
```

## iPhone 使用思路

iPhone 不能像 Android 一样直接安装 APK。自用阶段最简单方式是：

1. 用 Xcode 打开 Flutter 生成的 iOS 工程。
2. 连接 iPhone。
3. 选择自己的 Apple ID 开发团队。
4. 从 Xcode 运行到真机。

如果后续要让朋友也方便安装，再考虑 TestFlight。

## 数据迁移

从旧手机迁移到新手机：

1. 旧手机打开“复盘”。
2. 找到“数据备份”。
3. 点击“生成备份码”。
4. 点击“复制备份码”。
5. 把备份码发到新手机。
6. 新手机打开“复盘”，粘贴到“导入备份码”输入框。
7. 点击“导入备份码”。

## 发布前检查

每次打包前运行：

```bash
cd mobile
flutter test
flutter build web
flutter analyze
```

由于项目路径含中文，`flutter analyze` 如果在原路径异常，可复制到英文临时路径后检查。
